# Security policy

WaveBench is a static web page: files are read and processed in the browser, nothing is uploaded, and the page makes
no network requests (the browser checks in CI assert this).

If you find a security problem – for example a file that makes the page run code, leak data or crash in a way that
could be abused – please report it privately to kilic_kursat@hotmail.com rather than in a public issue. Include the
steps and, if possible, the file. You will get an answer within a week, and a fix will be released as soon as possible
with credit if you want it.

Only the latest release and the live site are maintained.
